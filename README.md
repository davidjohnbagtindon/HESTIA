# HESTIA
### Home-based Elderly Safety through Technology Integration and Assistance
A smart home-based elderly monitoring system integrating computer vision, audio recognition, and an IoT-enabled emergency wearable switch.

**Thesis Title:** Smart Home-Based Elderly Monitoring System Integrating Computer Vision, Audio Recognition, and Emergency Wearable Switch

## 📌 About the Project

HESTIA is a smart home-based elderly monitoring system designed to provide multiple ways for elderly individuals to request emergency assistance. It integrates computer vision, audio recognition, and an IoT-enabled emergency wearable switch into a centralized smart home environment.

Using ESP32 and Home Assistant, the system coordinates emergency events and facilitates notifications to authorized family members or caregivers.

## ⚙️ Key Features

- **Computer Vision:** Detects and recognizes predefined emergency hand gestures using MediaPipe.
- **Audio Recognition:** Detects a customized wake word, predefined voice commands, and selected abnormal household sounds.
- **Emergency Wearable Switch:** Provides a physical emergency button for manual alert activation.
- **Smart Home Integration:** Uses Home Assistant as the central platform for system integration, automation, and monitoring.
- **Emergency Notifications:** Facilitates alerts to authorized family members or caregivers.

## 🛠️ Technologies

- ESP32 Microcontroller
- Python and C++
- MediaPipe
- Home Assistant
- Internet of Things (IoT)
- Arduino IDE
- Visual Studio Code
- PCB Design and Fabrication Tools

## 🎯 Project Objectives

1. Develop a computer vision component for emergency hand gesture recognition.
2. Develop an audio recognition component for wake word and voice command detection.
3. Develop an IoT-enabled emergency wearable switch.
4. Integrate the three assistance mechanisms into a unified smart home monitoring system.
5. Evaluate the system's accuracy, response time, and notification performance.

## 🔬 Project Scope

The prototype will be implemented within a single-room residential environment. It focuses on emergency assistance through hand gestures, voice commands, and manual wearable switch activation.
